# 应用锁

给指定应用加一道密码。打开被锁的应用时，整屏弹出密码框，输对了才放行。

- 名称：应用锁
- 包名：`com.xiaozhan.yyT`
- 系统：Android 7.0 ~ 11（minSdk 24 / targetSdk 30）
- 密码上限：**100000 位**（纯数字，自带数字键盘，不调系统输入法）
- 应急后门：在锁界面**双击密码框**，会弹出系统输入框，输入 `6767` 直接解锁

## 首次打开会自动带你授权

第一次运行 App 会依次跳转三个系统页面，你只要点确认就行，界面里没有再放「点我开启」这类按钮：

1. 悬浮窗 / 显示在其他应用上层
2. 忽略电池优化
3. 无障碍服务（**这一项最关键，不给就完全不拦截**）

每项最多自动跳 2 次，之后不再骚扰，首页顶部那一行会显示当前缺哪项，点那行也能补。

## 用起来

1. 打开应用锁 → 点「设置密码」自己输，或者点「随机生成一个密码」
2. 点「添加应用」→ 进搜索页 → 输入应用名称或者包名（比如 `com.tencent.mm`）→ 列表里点一下那个应用，看到右边变成「已锁」就加上了
3. 首页「已锁定的应用」会列出来，每行右边有「移除」
4. 这时再去打开被锁的应用，会直接整屏弹出密码框

## 拦截是怎么实现的

用无障碍服务（AccessibilityService）监听窗口切换，拿到当前前台应用的包名，命中锁定清单就拉起密码界面。

- 自己 App 的界面、系统界面（`com.android.systemui`）不拦
- 输对密码后，这个应用 2 分钟内不再重复弹；切到别的应用会清掉这条放行记录，再切回来重新锁
- 密码框会盖住被锁应用的画面，返回键无效，只能输密码

## 应急解锁

万一忘记密码，进不了被锁的应用（比如把「设置」也锁了）：

1. 在锁界面**双击密码框**，弹出系统输入框
2. 输入 `6767`，点确定 → 直接放行

> 想换这个应急码，改 `Prefs.java` 里的 `BACKDOOR`。

## 源码结构

```
src/com/xiaozhan/yyT/
├── MainActivity.java              首页：密码、已锁列表、权限自动引导
├── AppListActivity.java           添加应用：按名称/包名搜索，点一下加锁
├── LockActivity.java              锁界面：数字键盘 + 双击后门
├── LockAccessibilityService.java  无障碍服务：识别前台应用并拦截
└── Prefs.java                     密码、锁定清单、放行记录、应急码
res/xml/accessibility_service_config.xml   无障碍服务配置
build.sh                           一键打包
```

## 注意

- 这是第三方拦截，不是系统级应用锁。重启手机后无障碍服务一般会自动恢复，但如果系统限制了，去无障碍设置里看一眼还在不在
- 国产 ROM 后台管控严，建议同时给它自启动、后台高耗电不限制
- 别把「设置」和「应用锁」本身锁进去，不然出问题不好救
