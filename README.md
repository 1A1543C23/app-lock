# 应用锁

给指定应用加一道密码。打开被锁的应用时，整屏弹出密码框，输对了才放行。

- 名称：应用锁
- 包名：`com.xiaozhan.yyT`
- 系统：Android 7.0 ~ 11（minSdk 24 / targetSdk 30）
- 密码上限：**100000 位**（纯数字，自带数字键盘，不调系统输入法）
- 应急后门：在锁界面**双击密码框**，会弹出系统输入框，输入 `6767` 直接解锁
- **把主界面从任务列表里划掉，拦截依然生效**

## 首次打开会自动带你授权

第一次运行 App 会依次跳转三个系统页面，你只要点确认就行，界面里没有再放「点我开启」这类按钮：

1. 悬浮窗 / 显示在其他应用上层
2. 忽略电池优化
3. 无障碍服务（**这一项最关键，不给就完全不拦截**）

每项最多自动跳 2 次，之后不再骚扰，首页顶部那一行会显示当前缺哪项，点那行也能补。

## 用起来

1. 打开应用锁 → 点「设置密码」自己输，或者点「随机生成一个密码」
2. 点「添加应用」→ 进搜索页 → 输入应用名称或者包名（比如 `com.tencent.mm`）→ 列表里点一下那个应用，看到右边变成「已锁」就加上了
3. 首页「已锁定的应用」会列出来，每行右边有「移除」
4. 这时再去打开被锁的应用，会直接整屏弹出密码框
5. 点「监测日志」能看到每一次识别和拦截的记录

## 拦截是怎么实现的

同一个 APK 里拆成两个进程：

- **主进程**：首页、添加应用、监测日志，只负责改配置
- **`:guard` 守护进程**：无障碍监听 + 悬浮窗锁界面 + 前台常驻服务 + 配置存储

主界面被划掉时，死掉的只是主进程，守护进程带着前台服务（通知栏那条「应用锁 守护中」）继续跑，拦截不受影响。两个进程之间用 `ConfigProvider` 传配置，主界面关掉也不会丢密码和清单。

识别前台应用有两条通道，任意一条命中就弹：

1. 无障碍服务（`TYPE_WINDOW_STATE_CHANGED`）—— 实时
2. `UsageStatsManager.queryEvents` 轮询 —— 每 1.2 秒查一次最近 5 秒的前台应用，需要「使用情况访问」权限

锁界面是 `WindowManager` 的 `TYPE_APPLICATION_OVERLAY` 悬浮窗，不是 Activity：

- 按 Home 键回桌面它也还盖着
- 右上角「取消」会先回桌面再撤掉悬浮窗，并且把目标应用继续保持锁定状态，取消之后照样打不开
- 输对密码后这个应用 2 分钟内不再重复弹；切走再切回来重新锁
- 自己 App 的界面、系统界面（`com.android.systemui`）不拦

## 应急解锁

万一忘记密码，进不了被锁的应用（比如把「设置」也锁了）：

1. 在锁界面**双击密码框**，弹出系统输入框
2. 输入 `6767`，点确定 → 直接放行

> 想换这个应急码，改 `Prefs.java` 里的 `BACKDOOR`。

## 源码结构

```
AndroidManifest.xml                双进程声明（:guard）+ 前台服务 + 无障碍 + Provider
src/com/xiaozhan/yyT/
├── MainActivity.java              首页：密码、已锁列表、开关、诊断
├── AppListActivity.java           添加应用：按名称/包名搜索，点一下加锁
├── MonitorActivity.java           监测日志：实时识别/拦截记录
├── LockActivity.java              锁界面（没有悬浮窗权限时的备用方案）
├── LockOverlay.java               锁界面主路径：全屏悬浮窗
├── LockAccessibilityService.java  无障碍服务：双通道识别前台应用并拦截
├── GuardForegroundService.java    守护进程的前台服务，常驻通知
├── ConfigProvider.java            跑在 :guard 里，主进程通过它读写配置
├── Config.java                    主进程侧的 Provider 客户端
└── Prefs.java                     密码、锁定清单、放行记录、日志
res/xml/accessibility_service_config.xml   无障碍服务配置
res/layout/                        首页 / 锁界面 / 应用列表 / 监测日志
res/drawable-nodpi/                图标
build.sh                           一键打包
```

## 注意

- 这是第三方拦截，不是系统级应用锁
- 国产 ROM（OriginOS / HyperOS 等）后台管控很严，想让守护进程活得久，还要给三样：**自启动允许**、**后台高耗电不限制**、**任务列表加锁**
- 无障碍权限有可能被系统在长时间休眠后自动收回，回收后就只剩轮询兜底，去无障碍设置里看一眼是否仍开启
- 别把「设置」「无障碍」「应用锁」本身锁进去，不然出问题不好救
- 开源版里应急码 `6767` 是公开的，自己用可以，别指望它防住懂行的人
